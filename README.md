# 🎃 Generador de Bingo Musical 🎵 --basada en el código de Chris Osric (https://osric.com/bingo-card-generator/)

¡Bienvenido/a! Esta es una aplicación web sencilla, interactiva y lista para usar para crear **cartones de bingo personalizados** (por ejemplo, para noches de bingo musical, fiestas de Halloween, reuniones familiares o eventos con amigos).

---

## 🚀 ¿Cómo usar o probar la aplicación? (Sin saber nada de GitHub)

No necesitas conocimientos técnicos ni saber programación para utilizar esta aplicación. Tienes dos formas muy fáciles de abrirla:

### Opción 1: Abrir directamente en tu navegador (La forma más fácil)
1. Haz clic en el botón verde de GitHub arriba a la derecha que dice **`Code`** y selecciona **`Download ZIP`**.
2. Descomprime la carpeta ZIP en tu ordenador (clic derecho > *Extraer todo*).
3. Entra en la carpeta y haz **doble clic en el archivo `index.html`**.
4. ¡Listo! Se abrirá automáticamente en Google Chrome, Safari, Firefox o tu navegador habitual. No requiere instalar nada.

---

### Opción 2: Ejecutar con Node.js (Para desarrolladores o servidores locales)
Si tienes **Node.js** instalado y prefieres correr el servidor web local:
```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar el servidor
npm start
```
Luego abre tu navegador en: [http://localhost:3000](http://localhost:3000)
